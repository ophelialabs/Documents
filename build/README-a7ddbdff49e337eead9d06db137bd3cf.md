# Subsidiaries

Use this directory for one page or folder per subsidiary. Keep legal-entity information here and link to technical implementation details in the relevant Technology & Infrastructure area.

## Navigation

- [Subsidiary A](subsidiary-a/README.md)
- [Subsidiary B](subsidiary-b/README.md)

## Documentation Template

Each subsidiary should document:

- Legal identity and jurisdiction
- Ownership and reporting relationships
- Mission, products, and business role
- Operations and responsible teams
- Technology, cloud, and system dependencies
- Security, regulatory, and compliance obligations
- Key contacts and source systems
